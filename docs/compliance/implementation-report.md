# IMPLEMENTED

Implementeret lokalt 2.–3. oktober 2026 mod den oprindelige 23-punktsliste. Rapporten blev udarbejdet før commit/push. Axel har efter gennemgangen bedt om commit og push; produktionsmigration eller destruktiv ændring af produktionsdata er ikke udført. De nye databaseflows kræver migrationen før udgivelse. Rapporten beskriver teknisk implementation og verificering; den er ikke en erklæring om juridisk compliance.

Den tilføjer service-only RLS-tabeller, uforanderlige dokumentarkiver, retention-/auditinfrastruktur og SQL-funktioner med ejerkontrol. De ændrer ikke eksisterende kunders accepthistorik. # VERIFIED

- **Lint:** bestået uden fejl eller advarsler.
- **Typecheck:** bestået med `tsc --noEmit`.
- **Hele testsuiten:** 79 tests; 78 bestået, 0 fejlet, 1 eksisterende offentlig HTTPS/netværkstest sprunget over.
- **Nye integrationstests:** migrations og SQL-funktioner køres i isoleret PGlite/PostgreSQL. Transport/Auth/Stripe/mail er mocks, så tests ændrer ikke produktion. Tests kontrollerer service-only grants/RLS, tenant isolation, forkert ejer, Origin, falske adminheaders, MFA, arkivhash/immutabilitet, ingen accept-backfill, eksport uden secrets, store datamængder, atomisk sletning, konto-cascade, retention/idempotens og jobfejl.
- **Widget:** faktisk `public/widget.js` eksekveres i tests. AI-oplysning kan ikke fjernes gennem custom branding; usikre privacy-links afvises; der skrives ikke persistent storage eller fontlinks.
- **Browser:** den lokale app viste `/dpa`, `/subprocessors`, `/terms`, `/privacy` og `/cookies` med fungerende krydslinks. DPA er synligt udkast. Privatlivspanelet er kontrolleret i preview på desktop og mobil; det er ikke en produktionslogin-/dataskrivningstest. Den rigtige widget er kontrolleret ved 1280×720 og 390×844. Ingen chat, ordredata eller supportsag blev indsendt.
- **Samtykke i browser:** accept indlæste Plausible/Vercel Speed Insights scripts; afvisning fra Administrér cookies genindlæste siden, og DOM indeholdt derefter ingen af disse scripts. Runtime-tests dækker fortsatte kald fra allerede indlæste scripts og sendBeacon. Dette er ikke en fuld produktionsnetværkscapture.
- **Produktion, read-only i den indledende audit:** projektregion eu-central-1; ejer-RLS på businesses/conversations/documents/customer_messages; commerce/server-tabeller begrænset; følsomme SQL-funktioner service-only; virksomhedens relationer har delete-cascade. Fire eksisterende virksomheder havde 90-dages chatretention. Nye ændringer er endnu ikke anvendt dér.
- **Secrets:** scan af tilføjede diff-linjer og nye source/docs/tests fandt 0 credential-mønstre. Ingen credential-mønstre blev fundet i ændringerne, som efterfølgende er godkendt til commit/push af Axel. Dette er en ændringsscan, ikke en fuld historisk secrets-audit.
- **Diffkontrol:** `git diff --check` bestået.
- **Udgivelsesbuild:** `npm run build` bestået. Next.js kompilerede og genererede de offentlige sider og nye API-routes. Første kørsel kunne ikke hente de eksisterende Google Fonts under netværksbegrænsningen; kørsel med netværksadgang lykkedes. Sitefonts pakkes lokalt af Next.js; widgetten indlæser ingen Google Fonts.

Supabase full-stack staging, faktiske Cron-kørsler, emails, Stripe Checkout, leverandørkontrakter og restore er ikke verificeret af lokale mocks/preview. Disse grænser er konkrete releasekrav.
